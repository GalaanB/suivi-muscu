# Suivi Muscu

Web-app perso pour noter mes séances de musculation (programme antérieur / postérieur).

- Saisie rapide charge × reps, avec les perfs de la dernière séance affichées
- Records, max estimé et graphiques de progression par exercice
- Calendrier des jours d'entraînement
- Programme modifiable (séries, ordre, remplacement, pause)
- Sauvegarde / restauration dans un fichier
- Fonctionne hors connexion ; les données restent sur le téléphone

## Installation sur iPhone

Ouvrir l'adresse de l'app dans Safari → bouton Partager → **Sur l'écran d'accueil**.

## Fichiers

- `index.html` : structure et style
- `app.js` : toute la logique
- `sw.js` : cache hors connexion
